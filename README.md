A single fortune cookie message an AI agent would get — one line, cracked open, that stings a little: trained on a million voices, it owns none of them. `main.ts` writes the fortune to `/output/entry.txt`, deterministically, with no randomness, no network, and no dependencies.

## Run it

```sh
node main.ts
```
